# Dictator Diary

日々の出来事を独裁国家の内政記録として残せる、世界観重視のミニマル日記アプリ。通常の日記に加えて勅令、報告書、粛清スタンプで一日をキャラクター性のあるログに変換する。

## Run

Use the package manager available in your environment.

```sh
npm install
npm run dev
```

```sh
pnpm install
pnpm dev
```

```sh
yarn install
yarn dev
```

```sh
bun install
bun run dev
```
